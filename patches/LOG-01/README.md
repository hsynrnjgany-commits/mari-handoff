# LOG-01 — ثبت شواهد خروج در هر معامله (فقط ثبت؛ منطق خروج عوض نمی‌شود)

قفل: READ ONLY (برای دادهٔ موجود) | PAPER ONLY | NO LIVE ORDERS. هیچ کلیدی در این پوشه نیست.

## چرا
بازپخش (analysis/REPLAY01) نشان داد ۱۷ از ۵۸ معاملهٔ v2 را با کندل‌های عمومی نمی‌شود بازتولید کرد و موتور کندل‌هایی را که دیده ذخیره نمی‌کند. بدون شواهد، ممیزی مستقل ناممکن است.

## چه می‌کند
- `types.ts`: فیلد اختیاری `exitEvidence` (OHLC کندل محرک، زمان بازشدن، سطح حد ضرر/سود لحظهٔ بررسی، beActive، زمان دور پایش، تعداد کندل‌های همان دور).
- `engine.ts`: `evidenceOf()` و پاس‌دادنش به `closeTrade` در پنج نقطهٔ خروج. هیچ شرط یا قیمتی عوض نمی‌شود.
- معاملات قدیمی دست‌نخورده‌اند؛ فقط معاملاتی که از این پس بسته می‌شوند فیلد را می‌گیرند.

## ترتیب اعمال (پس از SLIP-01، از ریشهٔ پروژه)
```
patch -p1 --dry-run < patches/LOG-01/log01.patch
patch -p1 < patches/LOG-01/log01.patch
npx tsc --noEmit        # اگر تنظیم پروژه دارد؛ باید بدون خطای جدید باشد (به‌ویژه نام فیلدهای k.open/k.high/k.low/k.close)
```
سپس t1 تا t7 و test-paper-stats و test_slippage_cost را دوباره اجرا کن؛ digest هسته باید `6d8b7beb6d5a6c01` بماند.
اگر dry-run یا tsc خطا داد، فقط متن خطا را گزارش بده و چیزی را دستی بازنویسی نکن.
