# candles_for_trades — کندل‌های خام برای ۷۴ معاملهٔ paper

قفل: READ ONLY | PAPER ONLY | NO LIVE ORDERS. هیچ کلید یا توکنی در این پوشه نیست.

## این فایل چیست
`candles_for_trades.jsonl` — برای هر یک از ۷۴ معاملهٔ بسته‌شدهٔ `data/paper-trades.json`، کندل‌های خام ۱ساعتهٔ بازار از **۱۰ کندل قبل از ورود** تا **کندل خروج**. هر خط یک کندل:

```json
{"tradeId":"...","symbol":"...","tf":"1h","t":<open_ms>,"o":...,"h":...,"l":...,"c":...,"v":...}
```

- `t` = زمان باز شدن کندل به میلی‌ثانیه (UTC، تراز ساعتی) — هم واحد با `entryTime/exitTime`.
- ترتیب: بر اساس tradeId (ترتیب دفتر) و سپس `t` صعودی.

## منبع و تایم‌فریم
- تایم‌فریم: **1h** — همان `interval` موتور (`src/lib/paper/types.ts`: `interval: "1h"`).
- منبع: **فقط همان دو endpoint که موتور خودش استفاده می‌کند** (`src/lib/market/provider.ts`):
  - primary: `https://api.toobit.com/quote/v1/klines` (۷۲ معامله مستقیم از این‌جا)
  - fallback: `https://data-api.binance.vision/api/v3/klines` (۲ معامله: ۱ معاملهٔ USDCUSDT-مانند که toobit پاسخ خالی داد و ۱ معاملهٔ NEOUSDT که در اجرای اول از هر دو منبع خطا داد و در تلاش دوبارهٔ منفرد از fallback کامل شد)
- هیچ منبع ناشناسی استفاده نشد؛ هیچ کلیدی لازم/استفاده نشد (هر دو endpoint عمومی‌اند)؛ فقط GET.
